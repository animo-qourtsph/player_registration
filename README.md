# Animo Pickleball Cup 2026 — Player Registration v23

## v23 — Mobile UI / UX improvements

This update improves the player site's mobile experience, especially during registration.

### Highlights
- Cleaner mobile registration layout
- Better top spacing, step spacing, and form spacing
- More compact and readable progress panel on phone/tablet
- Better mobile sticky Back / Continue bar
- Larger and friendlier mobile form fields
- Improved jersey preview layout on mobile
- Better review-card readability on small screens
- Lookup and confirmation views improved for mobile
- Footer hidden on registration, lookup, and confirmation views to reduce clutter

### Technical note
The active player view is now tracked on the `<body>` so view-specific mobile UX behavior can be controlled more cleanly.
