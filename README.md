# Animo Pickleball Cup 2026 — Player Registration v20

## v20 — Personalized jersey highlight

The Player Registration experience now gives the personalized tournament jersey a dedicated visual moment.

### Home page
A new **Your name. On your jersey.** section highlights:
- Personalized jersey-back name
- Separate jersey name for Player 1 and Player 2
- Exact spelling and capitalization
- Clear reminder to review the name before submission
- Illustrative pair-jersey preview

The jersey visual is intentionally marked as an illustrative personalization preview so it does not imply that the final jersey artwork is already approved.

### Registration form
The old plain jersey-name input is replaced by a dedicated personalization panel for each player.

As the player types their jersey name, a **live jersey-back preview** updates immediately.

This makes the jersey field feel like a tournament benefit instead of just another required form field.

All v19 registration logic, status lookup, and automatic email-trigger preview behavior remain unchanged.
