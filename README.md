# Animo Pickleball Cup 2026 — Player Registration v24

## v24 — Player badge fix

The **PLAYER 1 / PLAYER 2** badge inside the Level Verification header is now treated separately from the registration progress chips.

### Fixes
- PLAYER 1 / PLAYER 2 can no longer wrap into two lines.
- Badge uses intrinsic width and never shrinks.
- Level Verification header uses a two-column grid on desktop/tablet.
- On very small phones, the badge moves above the heading instead of being squeezed.
- Global status pills now use single-line text safely.

All v23 mobile UX improvements and registration logic remain unchanged.
