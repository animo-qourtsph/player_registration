# Player Production 1.1.0 — Adaptive UX Refresh

Preserved:
- Production 1.0 API contract and schema guard
- Pair-only registration
- Live Supabase tournament/division/payment configuration
- DUPR and no-DUPR validation
- Shirt size and jersey personalization
- Required payment metadata/proof
- Client-side proof compression
- Waiver gate and 24-hour saved drafts
- Egress-safe registration tracker
- Secure single-registration lookup

UX changes:
- Landing remains brand/editorial.
- Registration switches to a quieter application interface.
- Desktop uses a narrower focused registration workspace.
- Tablet uses a sticky horizontal step navigator and efficient two-column forms.
- Mobile uses single-column task surfaces, 56px inputs and sticky thumb-friendly actions.
- Review screen uses fewer borders and stronger information hierarchy.
- Confirmation/status screen is styled as a clear registration tracker.
- "Confirmed" wording is replaced by the final Approved workflow.
